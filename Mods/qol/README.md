# qol

Quality-of-life systems such as controller improvements, stash, loot filtering, hotkeys and interface options.

## Implemented RTT extensions

- Lua-driven loot filter that only changes ground-label visibility.
- Monster resistance display: hovering a monster shows its current Magic / Fire / Lightning resistances and immunities immediately, including unique monsters. This is presentation-only and does not modify combat calculations, RNG, saves or network state.
