## Classification

- Adapt/pin — use upstream code with exact provenance and licence compliance.
- Reimplement — reproduce behaviour with new Return to Tristram code/data.
- Reference first — study design before deciding on adaptation.
- Reference only — no source import planned.
- Reject — intentionally excluded.
