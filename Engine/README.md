# Engine

Reserved for the DevilutionX engine integration.

Plan:
- pin a known-good DevilutionX upstream revision;
- keep upstream changes auditable;
- minimise invasive engine patches;
- expose Return to Tristram gameplay through data, scripting and thin hooks where possible.

No DevilutionX source is vendored in the foundation reset yet. The next milestone is to select and record the exact upstream baseline before importing code.
